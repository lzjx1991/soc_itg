# 需求清单与开放问题（soc_itg）

> 状态：需求梳理阶段。带 ★ 的为影响架构的关键项。
> 已拍板的决策见 `docs/design-decisions.md` 第 3 节。

---

## A. 输入与数据模型

- **A1** SoC 组装描述谁写、怎么来？手写 YAML，还是从别处导出？（默认：设计工程师手写 YAML）
- **★A2** IP-XACT 版本？2009 / 2014 / 2022？（本机现为 2009；是否统一到 2022 待定）
- **A3** IP-XACT 文件组织：一 IP 一个 XML，还是打包？
- **A4** 除 IP-XACT 外，IP 是否还需额外元数据（license、依赖、版本）？放哪？
- **A5** SoC 描述是否支持多级/子系统复用？（默认：支持）
- **A6** 一份 SoC 描述需覆盖哪些信息：实例/连接/地址/时钟/复位/电源/中断/DFT？

## B. RTL 组装与 top 生成

- **B1** 生成语言与风格：Verilog-2001 / SystemVerilog？是否用 SV interface？（默认：SystemVerilog）
- **B2** 连线方式：信号级显式连线，还是按接口自动展开？（默认：接口自动展开）
- **B3** 是否做位宽适配 / 协议转换？（默认：只做位宽检查，不做转换）
- **B4** 层次：单层 flat 还是多级 hierarchical？（默认：支持多级）
- **B5** 生成 top 的文件组织：单文件 vs 按域拆分？
- **B6** 命名/编码规范是否有硬性要求？
- **B7** 输出只到 RTL，还是也生成综合脚本 / SDC 骨架？（默认：只 RTL）

## C. CSR 生成

- **★C1** 第三方给的是 IP-XACT 还是 SystemRDL？（决定 CSR 输入源）
- **C2** CSR 从端协议：APB / AHB / AXI-Lite？（默认：APB）
- **C3** 输出产物清单：RTL、C header、UVM RAL、文档、寄存器表？
- **C4** 是否需要 field 级属性（rw/ro/w1c/rc）、字节序、复位值？
- **C5** CSR 自动实例化进 top，还是独立交付？
- **C6** C header 命名规范是否与某 SDK 对齐？

## D. 流程编排

- **★D1** 要编排的步骤全集：lint（VCS/SpyGlass）、CDC/RDC、综合（DC）、形式（Formality）、时序（PT）、DFT？还有别的？
- **D2** 工具版本/许可证如何选择（module 系统 / 固定版本）？
- **D3** 触发方式：CLI 单命令，还是 YAML 定义流程？
- **D4** 除 EDA 外，生成物是否也要增量？（默认：都要增量）
- **D5** 失败/超时/日志/报告归档要求？
- **D6** 是否要并行跑多任务？（默认：要）

## E. 检查器

- **E1** 必需检查项清单（地址冲突/连接完整性/位宽/CDC/电源域…）
- **E2** 检查结果分级，是否阻断生成或流程？（默认：error 阻断，warning 不阻断）
- **E3** 报告格式（文本/HTML/JSON/CI 注解）？（默认：文本 + JSON）

## F. IP / 配置 / 版本管理

- **★F1** git 仓库结构：monorepo？每 IP 一个 repo + submodule？独立 repo + catalog 引用？
- **F2** IP 版本标识：semver / git tag / commit hash？
- **F3** 配置文件是锁定快照还是引用最新？（默认：lock 快照）
- **F4** catalog 从 IP-XACT 自动扫描，还是人工登记？（默认：自动扫描）
- **F5** 需要「配置矩阵」（同 IP 多配置）批量构建吗？

## G. CLI / API / GUI

- **G1** CLI 命令清单？（init / validate / generate / check / run / report …）
- **G2** 是否对外 Python API？（默认：要）
- **★G3** GUI 做什么：只读可视化 / 可视化编辑 / 触发流程？（关键，需明确）
- **G4** GUI 形态：Web 还是桌面？（默认：Web）
- **G5** GUI 优先级：P0 还是后期？（默认：后期）

## H. 非功能 & 协作

- **H1** 团队规模，几个人用？
- **H2** 运行环境：单机 Linux，还是共享服务器多用户？
- **H3** SoC 规模量级：多少 IP / 多少寄存器 / 多少实例？
- **H4** 与现有流程脚本：替换还是并存？
- **H5** 交付时间预期 / 里程碑？
- **H6** 谁维护这套工具？
- **H7** 测试 / 文档要求？
